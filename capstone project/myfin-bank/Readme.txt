Backend :
installrequired packages:
-----------------------------------------
npm init -y
npm install express mongoose bcryptjs jsonwebtoken dotenv cors nodemailer socket.io
npm install --save-dev nodemon
npm install --save-dev mocha chai supertest

node server.js

npm test
