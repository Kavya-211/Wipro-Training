Extract the folder smartlearn-portal
Install mangodb
Make sure MongoDB is running locally on:mongodb://127.0.0.1:27017
-----------------------------------------
Open backend terminal
cd backend
npm install
node server.js
http://localhost:5000

Open backend terminal
cd frontend
