Mock Practice Assessment – Front-End & TypeScript
This project implements a complete front-end solution using HTML, CSS, Bootstrap,
JavaScript (ES6), Fetch API, and TypeScript. It includes a responsive event homepage,
an interactive event dashboard with filtering, and a TypeScript-based customer
registration module. All modules run successfully and meet the assessment requirements.

How to Run:
1. Open index.html files in browser
2. For User Story 2, keep events.json in same folder
3. Compile TypeScript using:
   tsc CustomerModule.ts
